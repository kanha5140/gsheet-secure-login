# 🌌 Cyber-Auth: Google Sheets Powered Login System

A sleek, responsive, and secure subscriber login interface designed with a futuristic "Cyberpunk" aesthetic. This project demonstrates how to use **Google Sheets as a backend database** via **Google Apps Script** for lightweight authentication.

## ✨ Features
* **Futuristic UI:** Implements glassmorphism, CSS grid animations, and neon glow effects.
* **Serverless Backend:** No SQL or Node.js required—uses Google Sheets for easy user management.
* **Real-time Auth:** Fetch-based API calls to Google Apps Script for instant credential verification.
* **Security:** Responsive error handling with "Access Denied" animations and visual feedback.
* **Fully Responsive:** Optimized for both desktop and mobile environments.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript.
* **Backend:** Google Apps Script (Web App).
* **Database:** Google Sheets.
* **Typography:** Orbitron & Rajdhani via Google Fonts.

## 🚀 Quick Start
1.  **Prepare the Database:** Create a Google Sheet with columns for `username` and `password`.
2.  **Deploy Script:** Paste your Google Apps Script code and deploy it as a "Web App" with "Anyone" having access.
3.  **Link the Frontend:** * Open `index.html`.
    * Replace `const SCRIPT_URL` with your deployed Apps Script URL.
4.  **Launch:** Open `index.html` in any modern browser.
